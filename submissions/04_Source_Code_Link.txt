--------------------------------------------------------------------------------
 GITHUB REPOSITORY
--------------------------------------------------------------------------------

    https://github.com/shubhiscoding/Solana-Local-Indexer-Explorer

    Clone with:
        git clone https://github.com/shubhiscoding/Solana-Local-Indexer-Explorer.git

    Run with (Docker is the only prerequisite):
        cd Solana-Local-Indexer-Explorer
        docker compose up --build -d

    Then open:
        http://localhost:3000

--------------------------------------------------------------------------------
 WHAT IS IN THE REPOSITORY
--------------------------------------------------------------------------------

    docker-compose.yml              Orchestration: 4 services, 2 volumes,
                                    health-gated startup order
    validator/                      Solana test validator + Yellowstone gRPC
                                    Geyser plugin (multi-stage Dockerfile)
    indexer/                        TypeScript gRPC stream consumer, Prisma
                                    schema and migrations, 29 unit tests
    explorer/                       Next.js 16 app: 5 REST routes, 4 UI pages,
                                    9 unit tests
    docs/screenshots/               Interface screenshots
    README.md                       Quick start and user reference
    INSTALLATION_GUIDE.md           Step-by-step first-time setup
    TEST_CASES_AND_VALIDATION.md    Full 92-case test catalogue and results
